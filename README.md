## About the course

A free, self-paced course teaching Java and object-oriented programming from the 
ground up — variables, loops, and methods through to classes, interfaces, and 
data structures.

## Repository structure

```
java-programming-mooc/
├── java-programming-i/     # Part 1 – basics, variables, loops, methods...
│   ├── part01/
│   ├── part02/
│   └── ...
└── java-programming-ii/    # Part 2 – OOP, interfaces, collections...
```

Each `partXX` folder corresponds to a weekly section of the course, and each 
exercise lives in its own subfolder matching the course's naming convention.

## Running the exercises

Most exercises use the course's own build setup TMC plugin. To run an 
individual exercise manually:

```bash
cd java-programming-i/partXX/exercise-name
javac Main.java
java Main
```
